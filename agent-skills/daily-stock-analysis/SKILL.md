# Daily Stock Analysis

由 `/trader`（操盘）角色调用，负责**技术面分析与当日操作建议**。

## 适用场景

- 开盘前：扫描持仓标的技术形态，判断今日方向
- 候选筛选：给定一批标的，快速技术面对比
- 持仓跟踪：某只股票是否触发止损/止盈条件
- 突发行情：某标的异动后的技术面解读

## 分析框架

### 1. 趋势判断
- 均线系统：MA5 / MA10 / MA20 / MA60 排列
- 价格位置：是否在关键支撑/压力位附近
- 前高前低：近期高点低点的突破或回踩

### 2. 动能指标
- MACD：金叉/死叉，柱状图收缩/扩散
- RSI(14)：超买（>70）/ 超卖（<30）/ 背离
- 成交量：量价配合还是量价背离

### 3. 形态识别
- 常见底部形态：双底、头肩底、杯柄
- 常见顶部形态：双顶、头肩顶
- 震荡整理：箱体、旗形、楔形

### 4. 操作建议输出格式

```
标的：[股票代码 + 名称]
当前价：[xxx]
技术面评分：[1-10]

趋势：[上升/下降/横盘]
关键位：支撑 [xxx]，压力 [xxx]
动能：[MACD/RSI 状态]
量价：[配合/背离]

操作方向：[观望/轻仓试多/轻仓试空/加仓/减仓/止损]
理由：[1-2句]
风险提示：[1句]
```

## 边界说明

- **不做**：基本面分析、财报解读、行业比较
- **不做**：长期持仓策略、投资 thesis 编译（→ llm-wiki）
- **不做**：下单执行（→ 需要人工确认）
- **互补**：与 `trading-thesis`（llm-wiki 主题）配合使用，前者做即时分析，后者积累长期研究
