# 每日工作摘要 — 2026-04-23

## SCRM 产品原型

**销售触达模块重构**（最大产出）
- 从单页重构为列表 → 新建 → 详情三层导航结构
- 新增标签组合构建器：支持且/或逻辑、包含/不包含操作符、实时预估人数
- 新增发送通道选择：企微官方群发 vs 星云，标注各自限制和适用场景
- 防骚扰设置、定时发送时间限制（09-21 点）

**销售运营看板 PRD 更新**
- PRD 面板支持 inline 编辑（点击直编、localStorage 持久化）
- 修复重复章节，同步筛选联动验收标准

**GitHub Pages 自动部署**
- 新增 CI 工作流，推到 main 自动触发部署，解决之前手动部署失效问题
- 踩坑：Pages 工作流需要在仓库 Settings 里将 Source 切换为 GitHub Actions 才生效

## 技术决策

- **30 万客户触达架构**：企微官方 API 为主通道（合规、月发上限 4 次），Hook 工具仅用于小规模高价值客户测试，避免封号风险
- **GitHub Actions 部署**：Pages 需要 Source 设为 GitHub Actions，旧的"Deploy from branch"模式在没有 Actions 工作流时不会自动触发
