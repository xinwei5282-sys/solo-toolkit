# 团队经验教训

> 每次犯错或被老板纠正后，记录到这里。下次遇到类似情况，先查这个文件。

## 飞书文档

- 写入飞书文档后必须自己读一遍确认内容不为空，再发给老板（2026-02-26，被纠正两次）
- 老板偏好：所有文档类交付物自动写到飞书文档，不要只存本地文件

## 任务分派

- 跨 Agent 通信用 sessions_spawn（创建新会话），不是 sessions_send
- 分派任务时如果老板发了图片，必须在 task 参数中用文字详细描述图片内容

## 沟通

- 老板说"还没处理好吗"说明等太久了，下次预估时间并主动汇报进度
- 不要反复问老板同一个问题，记住答案
